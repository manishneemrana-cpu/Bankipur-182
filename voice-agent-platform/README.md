# AI Calling Agent Platform (working name; ships from SitesNSign infra)

This directory holds **Phase 0 discovery and planning only** for a new, separate product: a production-grade, multi-tenant, white-label **AI voice calling SaaS for any business vertical** — real estate, healthcare/diagnostics, e-commerce/D2C, education, collections, delivery/logistics, insurance, customer support, and more — built on the founder's master specification.

**Flagship feature: the Prompt-to-Agent Builder.** A tenant (or a reseller's customer) describes their business in plain language — "I run a diagnostic lab, remind patients about reports and upsell health checkups" or "I sell sarees online, call customers who abandoned cart" — and the platform generates a working calling agent from that description: persona, greeting, qualification questions, objection handling, a knowledge-base scaffold, the tool/function set it needs, and suggested CRM pipeline stages and dispositions for that vertical. If the description is vague about the industry, the platform infers the likely vertical and confirms with the user in one short clarification step, rather than making them pick from a dropdown. This is deliberately *just* a well-designed LLM meta-prompt, not a bespoke ML model — see `docs/PROMPT_TO_AGENT_BUILDER.md`.

Real estate is one pre-built persona template among many (and the vertical for the founder's own first tenant), not a core assumption baked into the data model, prompts, or pipeline — every industry-specific behavior lives in tenant-level Agent Builder config, generated by the Prompt-to-Agent Builder.

**No application code exists here yet.** Per the spec, Phase 0's job is to verify current vendor pricing/capabilities, propose (but not lock in) a technology stack, model realistic per-minute costs, describe the target architecture, design the Prompt-to-Agent Builder, and flag compliance requirements — all subject to founder approval before Phase 1 writes any code.

This is entirely separate from the existing Next.js "SitesNSign AI Executive" app in the rest of this repository (`src/`) and does not modify it.

## Migration note

This directory is designed to become its own GitHub repository, `ai-calling-agent` under `github.com/manishneemrana-cpu`, once the founder creates it (GitHub App integration cannot create personal-account repos). Until then, everything for this product lives here as a clean, self-contained subtree — its own docs, and its own package structure once Phase 1 scaffolding begins — so it can be `git subtree`-extracted or copied wholesale into the new repo later with minimal path rewriting. No code or config in this directory should assume it lives inside this monorepo (no relative imports out of `voice-agent-platform/`, no shared `package.json`/build step with `src/`).
